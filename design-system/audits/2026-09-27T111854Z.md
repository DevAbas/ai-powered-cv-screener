# Design Token Architecture Audit

- Project: ai-powered-cv-screener (`c2a7d2a`), with uncommitted changes
- Date: 2026-09-27
- Profile: terrazzo-tailwind-v4
- Token format: W3C Design Tokens (DTCG) 2025.10: 10 *.tokens.json files behind a resolver with sets foundation and semantic and one modifier, theme (light default, dark)
- Rules document: `DESIGN.md`

## Summary

| Part | Status | Summary |
|---|---|---|
| naming | met | Roles are named by purpose in kebab-case in both themes, and one mapping from id to class and variable (DESIGN.md, Overview: Reading the tokens) is enforced by the contract check and the token-classes lint. |
| tiers | partial | The token tiers hold and code states no colour outside them; the components contract still leaves out the empty-state headline and frame, the progress line's label at rest and the candidate name. |
| format | met | The tokens parse as DTCG 2025.10 through Terrazzo, both themes define the same 24 roles, and both stylesheets are built by Terrazzo behind a --check staleness gate and an edit-denying hook. |
| docs | partial | DESIGN.md explains every role and has a reading guide, but its prose restates token values (durations, container widths, blur) and component sizes that also live in code. |

Findings: 0 error, 2 warning, 2 info.

## Findings

### tiers

#### warning: The components contract leaves out components the code has: the empty-state headline and frame, the progress line's label at rest and the candidate name

- Rule: `tiers/components-read-roles`
- Id: `tiers/components-read-roles@DESIGN.md#components`
- Location: `DESIGN.md` at `components`
- Evidence: `DESIGN.md:9` `components:`
- Evidence: `src/components/ChatEmptyState/ChatEmptyState.tsx:71` `gap-x-5 text-display text-on-surface"`
- Evidence: `src/components/ChatEmptyState/ChatEmptyState.tsx:119` `className={cx("absolute size-4 border-primary", corner)}`
- Evidence: `src/components/Answer/CandidateName.tsx:11` `<span className="inline-flex items-center gap-1.5 text-headline-md text-on-surface">`
- Evidence: `DESIGN.md:134` `progress-line-shimmer:`
- Evidence: `src/components/ui/ThoughtLine/ThoughtLine.recipe.ts:8` `root: "inline-flex max-w-full flex-col items-start text-label-lg text-on-surface",`
- Why: The contract is the component tier: a component missing from it has roles that no check ties to it (principles 2). Lowered from error to warning because every entry in the contract names a role, and the prose (Components: Empty state, Progress line, Answer views) names these components' roles. The shimmer band's faded ends now have an entry (progress-line-shimmer); the label at rest does not.
- Fix: Add contract entries (for example empty-state-headline, empty-state-frame, progress-line, candidate-name) that name the roles and text styles the prose already gives them.

### docs

#### warning: DESIGN.md prose restates token values and component sizes that the tokens or the code also hold

- Rule: `docs/rules-hold-no-values`
- Id: `docs/rules-hold-no-values@DESIGN.md#`
- Location: `DESIGN.md`
- Evidence: `DESIGN.md:422` `a little past its mark (280ms, the overshoot easing); under reduced`
- Evidence: `src/components/ui/ColorModeButton/ColorModeButton.tsx:40` `motion-safe:duration-(--motion-duration-color-mode-turn) motion-safe:ease-overshoot`
- Evidence: `DESIGN.md:455` `as wide as it is tall and at most 33.75rem (540px) wide.`
- Evidence: `DESIGN.md:485` `middle. It opens 30rem wide, is dragged wider or narrower by`
- Evidence: `DESIGN.md:519` `over 200ms (decelerate) and fold over 150ms (accelerate), fading with`
- Evidence: `DESIGN.md:555` `easing). The other words blur 5px (500ms); the focused one is sharp.`
- Evidence: `src/components/ChatEmptyState/ChatEmptyState.tsx:90` `"motion-safe:blur-(--motion-blur-out-of-focus)"`
- Evidence: `DESIGN.md:366` `'primary' hairlines (1px in light, 0.5px in dark, where mint on near-black`
- Evidence: `src/styles/theme.template.css:34` `--cursor-grid-line-width: 1px;`
- Evidence: `DESIGN.md:415` `Sizes: 'xs' 1.875rem, 'sm' 2rem, 'md' 2.25rem tall.`
- Evidence: `src/components/ui/Button/Button.recipe.ts:33` `xs: "h-7.5 min-w-7.5 gap-1 [&_svg:not([class*='size-'])]:size-4",`
- Evidence: `DESIGN.md:442` `character 75ms apart, the full question held 1.5s, deleted at 30ms a`
- Evidence: `src/components/ChatComposer/typewriter.ts:9` `typeMs: 75,`
- Why: A value written in the rules document and again in tokens or code is two sources that drift (principles 1). The prose states the values of motion.duration-color-mode-turn, containers.question, containers.preview, motion.duration-medium/short, motion.blur-out-of-focus and motion.duration-focus-move instead of citing their ids, and repeats sizes that DESIGN.md itself says live in code (line 397). The contract check covers only the front matter, so this is a review item.
- Fix: Cite the token ids where a token exists (for example `motion.duration-color-mode-turn`, `containers.question`), and name the code constant instead of its number for component-owned sizes and timings (Button.recipe.ts, typewriter.ts, theme.template.css).

#### info: 20 of the 25 dark colour roles have no $description

- Rule: `docs/token-descriptions`
- Id: `docs/token-descriptions@tokens/themes/dark.tokens.json#color`
- Location: `tokens/themes/dark.tokens.json` at `color`
- Evidence: `tokens/themes/dark.tokens.json:6` `"surface": {`
- Evidence: `tokens/themes/dark.tokens.json:7` `"$value": "{palette.gray-dark-background}"`
- Why: The description travels with the token into every tool (DTCG Format 5.2.1). (https://www.designtokens.org/tr/2025.10/format/)
- Fix: Add the same $description as the light role, since a role keeps its meaning in every theme.

#### info: 20 of the 25 light colour roles have no $description

- Rule: `docs/token-descriptions`
- Id: `docs/token-descriptions@tokens/themes/light.tokens.json#color`
- Location: `tokens/themes/light.tokens.json` at `color`
- Evidence: `tokens/themes/light.tokens.json:6` `"surface": {`
- Evidence: `tokens/themes/light.tokens.json:7` `"$value": "{palette.gray-background}"`
- Why: The description travels with the token into every tool (DTCG Format 5.2.1). Only the four derived roles carry one here, and those four state their rules. (https://www.designtokens.org/tr/2025.10/format/)
- Fix: Give each role a one-line $description of its use, taken from DESIGN.md, Colors, and turn on Terrazzo core/descriptions for the role groups.
